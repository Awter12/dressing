# Agronomy Workshop Shopify theme

This is an installable Shopify Online Store 2.0 theme. It uses Shopify Liquid and Shopify's catalog, collections, pages, navigation, cart, and checkout. Product information is not hard-coded into the theme.

## Upload to Shopify

1. In Shopify admin, open **Online Store → Themes**.
2. Choose **Add theme → Upload zip file** and upload `agronomy-workshop-shopify-theme.zip` from the project folder.
3. Preview the uploaded theme, then publish it when you are ready.
4. In **Customize**, select a collection for the Featured collection section and set the navigation menu. The home page hero already has a source image URL; upload your own image to replace it if desired.

## Product catalog

The theme package does not create products. Import `shopify-products-import-draft.csv` separately from Shopify admin using **Products → Import**. The CSV currently marks products as drafts and not published to the online store, so review and publish them in Shopify after import. Add products to collections so they appear in the collection sections.

## Theme contents

- Home, product, collection, page, cart, search, and 404 templates
- Editable header/footer, editorial hero, and featured collection sections
- Responsive styling, Shopify product forms, prices, cart, and checkout links
